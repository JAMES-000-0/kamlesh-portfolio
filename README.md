## 🚀 Key Interactive Features

1. **3D Interactive Living Room Hero (Three.js):**
   - Cream sectional sofa with accent cushions and espresso coffee table.
   - Floor-to-ceiling windows with functioning vertical blinds, sheer curtains, and gold finial rods.
   - Real-time mouse and touch parallax camera tracking.
   - Interactive 3D Room Studio controls: switch wallpaper patterns in real time and rotate vertical blind slat angles from 0° (privacy) to 90° (daylight).
   - Graceful WebGL fallback and reduced-motion support.

2. **Official Brand Showcase:**
   - Prominently showcases the original Kamlesh Interiors banner and 5 product cards.

3. **Interactive 3D Product Showroom:**
   - **Wallpaper Studio:** Interactive pattern swatches with tactile zoom inspection.
   - **Vinyl Flooring Studio:** Wood tone switcher (Oak, Walnut, Ash, Teak) with resilience specs.
   - **Netlon Insect Screen Studio:** Ventilation and insect barrier facts with verified on-site photos.
   - **Curtain Rods Studio:** Architectural metallic finish comparisons (Brass, Matte Black, Gold, Nickel).
   - **Vertical Blinds Studio:** Interactive solar glare simulator with real-time slat louvers.

4. **Curated Portfolio & Verified On-Site Gallery:**
   - Features real client installation photos from Salem (Netlon window screens, screen doors, wide blinds, luxury drapery).
   - Fullscreen Lightbox modal with next/prev navigation and direct WhatsApp enquiry trigger.

5. **Customer Conversion & Enquiry Experience:**
   - Click-to-call buttons for both phone numbers.
   - Interactive quotation form with category selection, name, phone, and requirements.
   - Seamless WhatsApp enquiry generator sending formatted messages directly to `+91 99650 34444`.
   - Confetti celebration upon completion.

6. **Interactive Salem Showroom Section:**
   - Embedded interactive Google Map focused on Ponnammapet, Salem.
   - Direct button for turn-by-turn directions.
   - Clear showroom hours placeholder.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4
- **3D Engine:** Three.js
- **Icons:** Lucide React
- **Delight & Animations:** Canvas Confetti

---

## 💻 Development & Deployment Instructions

### 1. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
Generates an optimized, minified production build in the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```
